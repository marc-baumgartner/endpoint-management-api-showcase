# Logos for the Entra app registrations

The logo of the admin UI (favicon) as 215 × 215 PNG, under 100 KB, as Entra asks for (*App registrations → <app> → Branding & properties → Upload new logo*). Only the background colour differs.

| File | Suggested for |
|---|---|
| `emapi-graphite.png` | `EndpointManagement.Service` (the original colour) |
| `emapi-blue.png` | `EndpointManagement.AdminUI` |
| `emapi-teal.png` | `EndpointManagement.Client.<Name>` |
| `emapi-purple.png`, `emapi-amber.png`, `emapi-red.png` | spare, e.g. for a test or development tenant |
